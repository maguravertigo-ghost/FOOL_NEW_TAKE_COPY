# Smoke-тест (headless)

Прогоняет игру в jsdom без браузера: boot → все оверлеи меню → старт матча
в обоих режимах → пауза → выход в меню → повторный матч.
Ловит исключения и `console.error`, в конце печатает количество ошибок.

```bash
cd tools/smoke
npm install          # один раз
node smoke.mjs       # 0 ошибок → код возврата 0
```

Не входит в архив игры (папка `tools/` не нужна на хостинге).
